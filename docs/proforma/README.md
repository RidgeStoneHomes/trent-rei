# Landova proforma engine (v3)

Screens any U.S. parcel against every use, gives each one a max offer, and builds a prefilled proforma. It also learns from each org's uploaded proformas and actuals.

- Start with **BUILD_GUIDE.md** (also available as `Landova_Proforma_Engine_v3_Build_Guide.docx`).
- `Landova_Proforma_v3.xlsx` is the reference implementation. Regenerate it with `python3 build_v3.py`, then check it with `python3 verify.py`, which needs LibreOffice.
- `v2/` holds the previous version for comparison.

Every economic value is a placeholder until it is replaced with sourced data.
